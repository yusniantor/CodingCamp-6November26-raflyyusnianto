# DayFlow Project Instructions

## Project Overview
DayFlow is a personal productivity dashboard built using HTML, CSS, and vanilla JavaScript.

## Technical Requirements
- Use HTML, CSS, and vanilla JavaScript only.
- Store tasks, preferences, and quick links in browser Local Storage.
- Do not use a backend or frontend framework.
- Ensure compatibility with GitHub Pages.

## Required Features
- Live clock, date, and personalized greeting.
- 25-minute focus timer with Start, Stop, and Reset.
- Add, edit, complete, and delete tasks.
- Quick Links with Local Storage persistence.
- Light/Dark Mode.
- Custom greeting name.
- Duplicate-task prevention.

## File Structure
- index.html
- css/style.css
- js/script.js
- .kiro/steering/project.md
- README.md

Keep code readable, responsive, accessible, and easy to maintain.
